# Odin Recipes

A simple recipe website built as part of The Odin Project's Foundations course.
It has a home page linking to three recipe pages, each with an image,
a description, ingredients and steps.

## What I practiced

- Structuring a basic website with HTML
- Linking pages together with relative paths
- Adding ordered and un-ordered lists as well as different headings
- Adding images and organizing files into folders
- Using Git and GitHub to track and publish my work

## Recipes

- Baked Italian Chicken Rollatini
- Apple Cinnamon Rolls
- Mississippi Sloppy Joes
